# 🎯 Number Guessing Game

A beginner-friendly Python game where the computer randomly selects a number between 1 and 100, and the player tries to guess it.

## 🎮 How It Works

1. The computer generates a random number between 1 and 100.
2. Enter your guess.
3. The game gives you a hint:
   - **HIGHER** → Your guess is too low.
   - **LOWER** → Your guess is too high.
4. Keep guessing until you find the correct number.
5. When you guess correctly, the game displays **CORRECT!!**

## 🛠️ Concepts Used

- Python
- `random` module
- `random.randint()`
- `input()`
- `if / elif / else`
- `while` loop
- `break`
